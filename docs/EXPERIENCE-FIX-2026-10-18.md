# 卡顿、遥控与操作体验专项修复

本轮不新增首页、不改地区路由、不改正式版版本号、不发版。基于用户预览 46.1 日志中的真实主线程堆栈修复，保留此前本地未发布的启动与菜单改进。

## 根因与改动

1. `countryCode()` 原来每次调用构造正则，香港优先排序比较器重复调用地区判断。现将国家代码与 tvg-id 后缀固定正则预编译，香港优先改为稳定分区，每个频道只判断一次。
2. 频道主次排序原在比较器里重复归一化名称和识别分类，现预计算权重，并复用预编译的频道名称正则。
3. 手机频道过滤的谓词原可能对每个频道重新排序整份频道表。现使用后台生成的 `ChannelBrowseIndex`，一次生成地区、分类和排序权重，手机与电视界面复用结果；焦点和播放状态变化不重新构建索引。
4. 后台索引按输入快照发布，数据更新时不使用旧快照的分类。追加 `CHANNEL_INDEX` 日志，记录频道数、构建耗时和实际执行线程。索引不包含全局无界缓存，不改数据库结构或频道身份。
5. 播放画面确认键短按改为松开时触发；长按只打开详情，不提前执行短按。失去焦点取消未完成按键，避免弹层打开后释放键造成误触。
6. 播放画面方向键的系统重复事件不重复触发切台或控制面板，避免长按产生换台请求堆积；正常频道列表的方向键滚动仍保留。
7. 频道行去除重复的自定义长按处理，交由同一个 `combinedClickable` 分派，避免详情打开两次。
8. 打开节目单时记住发起操作的频道；关闭节目单后先滚动使该频道进入可见区，再在布局完成后恢复焦点。搜索按返回先关闭搜索、清空关键词，再恢复频道，不直接退出直播。
9. 继续保留上一轮修改：主菜单返回关闭菜单；退出应用明确确认；打开菜单聚焦当前页面；离开直播取消播放。

## 自动验证

新增纯 JVM 回归：确认键短按与长按互斥、重复事件与焦点取消；地区代码边界与别名、tvg-id 后缀；香港稳定顺序与主频道顺序；相同频道 ID 更改分组后索引更新；15000 个模拟频道的完整性与稳定顺序。大列表用例验证正确性，不将桌面 JVM 耗时当作电视性能指标。

新增 Android 回归用例：确认键按下不立刻执行、松开只执行一次；节目单关闭后焦点回原频道且没有触发播放。这些用例在本环境只编译，没有真机或模拟器执行条件。

## 设备验收步骤

在同一台电视、相同订阅与节点配置下，连续冷启动至少 5 次，分别记录：

- `first composition frame`、`library ready`、`CHANNEL_INDEX` 和所有 `MAIN_STALL` / `MAIN_RECOVERED`；首帧日志不是完整系统启动性能基准。
- 启动后首次按上下、确认、返回的实际响应情况。
- 观看时短按确认打开频道列表；长按确认只开详情；按住按键不连续打开弹层。
- 节目单右键打开、左键或返回关闭后，焦点和列表位置保留。
- 搜索返回、主菜单返回、退出确认取消、切到影视/代理/设置，逐项确认不误退出、不后台继续直播。

尚不能断言电视上一分钟卡顿全部解决：已处理日志明确指向的地区识别/排序热点，其他设备卡顿仍需新测试包的真机日志定位。云盘原 46.1 不包含本轮修复。
