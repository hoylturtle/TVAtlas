# tvbox-desktop 影视来源核查

目标仓库为 `hgtuj5688/tvbox-desktop`，本次按快照 `04274df786329cdb8f3ec79138a7e6f393d60dc1` 检查。用户给出的 `CT5XYQ3/hgtuj5688/tvbox-desktop` 不是可读取的 GitHub owner/repository 路径；通过公开检索确认上述仓库。

## 来源与现有 APP 的关系

仓库 `samples/public-sources.json` 包含五个苹果 CMS V10 接口：

| 来源 | 接口域名 | 与 TVAtlas 的关系 | 本次真实电影直链测试 |
|---|---|---|---|
| 非凡 | api.ffzyapi.com | 已有非凡，同一提供方的不同接口域名 | HTTP 403，响应明确提示地区拒绝 |
| 量子 | cj.lziapi.com | 已有，主要是路径尾斜杠差异 | m3u8 与媒体分片可读；抽样已确认赌场广告 |
| 电影天堂 | caiji.dyttzyapi.com | 已有，HTTP/HTTPS 差异 | HTTP 403，响应明确提示地区拒绝 |
| 光速 | api.guangsuapi.com | 相对当前内置列表为新增候选 | 媒体请求 HTTP 444 |
| 素博 | subocaiji.com | 相对当前内置列表为新增候选 | 媒体请求 HTTP 444 |

接口列表和搜索大多可读。一次量子列表请求为 503，随后其他请求成功，因此不能仅凭单次状态永久移除来源。以上是本次云端网络路径的结果；地区拒绝和其他连接失败不代表用户所在网络一定无法播放，也不能用它们判断视频有无广告。

三家同提供方来源不能作为三套全新内容计数；光速和素博目前只有 API 级可达证据，没有完整播放或无广告证据，故没有默认内置、替换旧来源或标为无广告。

## 广告实证

选取同一部影片《流浪地球2》（2023），严格区分 API 返回的分享网页与原生视频直链，不把分享页的 HTML 视为原生线路失败。

量子的原生 HLS 媒体播放列表可读，2618 个分片，总时长约 10468.8 秒。开始、中间和后段三处常规抽样可解码，但仅凭这些样本仍不足以判断没有广告。

播放列表另有三组相同的重复片段；定向解码第一组片段，画面明确包含赌场、博彩游戏及相关推广。三组插入区间为：

- 303.46–329.22 秒（约 05:03–05:29）
- 2008.93–2034.69 秒（约 33:29–33:55）
- 3832.31–3858.07 秒（约 63:52–64:18）

每段约 25.76 秒，同一组广告分片重复使用。该播放列表没有明确的 CUE-OUT／SCTE35 插入标记；这说明“没有检测到插入标记”不等于无广告。此结论只针对本次采样的这个版本，不外推成该来源所有影片都有广告。

不能将这些时间区间应用到其他影片或剪辑版本，也不能根据一般的 discontinuity 标记删除分片。当前 APP 的广告标记、换线、来源屏蔽和手动跳过功能仍用于用户反馈的具体版本。

## 探测脚本的其余候选

还检查了 `scripts/probe-apis.mjs` 列出的全部 30 个接口，不仅限于内置的五家。共 8 个接口在本次复测中返回非空列表和搜索结果（其中包括非凡的两个接口地址，不能当作两个新提供方）。其余请求出现 403、404、超时或隧道拒绝等问题；云端访问失败不能直接外推成用户网络下永久失效。

除内置来源外，无尽和优质的接口也可读，并能返回同一部电影的原生视频地址；但两者实际播放列表请求都返回 403，因此仍没有取得“可播放且无广告”的替换证据。

结论：可把兼容接口作为候选接入渠道，但本轮没有找到足以默认替换现有来源的已验证无广告新增来源。不能把外部仓库的探活结果当成广告认证。

## 兼容改动

仓库配置使用 `type: "cms"`，旧 TVAtlas 只接受数字 `type: 1`（也接受字符串数字 `"1"`）。已增加明确的 CMS 字符串别名识别：cms、maccms、apple、apples、苹果cms，大小写与前后空格可归一化。

数字类型 3 仍然按原 TVBox 的 Spider 类型处理，不照搬对方内部类型编号；HTML、规则站、未知 JSON 类型和 csp_ 条目不执行。原有 HTTP(S)、凭证、私网目标、响应大小与来源数量限制保持生效。

这是配置格式接入改动，不是无广告认证；没有自动合并外部来源到用户配置，没有清空来源或代理节点，没有公开发布。
