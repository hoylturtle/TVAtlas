# 影视缓存与节点测速修正

影视保留上次片单，刷新时先显示缓存。精确筛选缓存未命中时，从近期其他片单中筛选匹配的分类、类型、地区、年份及搜索词，最多读取 16 MiB / 13 个文件，仅保留七天内、仍属于当前来源的元数据。每个来源返回后保存片单，避免切页取消剩余请求时丢失全部缓存。播放地址不保存在片单缓存，选择影片后重新获取。首次没有匹配缓存的分类显示醒目的居中加载提示和来源进度。

手动节点测速原来整批 120 秒超时，节点多时会取消仍在排队的节点。改为每节点最多 15 秒，四并发、每节点三次采样；保留旧的自动短测整体 10 秒限制。单个客户端异常只影响该节点。已停用的节点不参与，测试中显示等待／进行中，失败节点计入已完成。

订阅名称中明确的“剩余：”“到期：”“重置：”“官网：”说明条目不导入为代理；旧订阅说明从节点视图和测试队列过滤，刷新订阅后从存储清理。手动添加的节点不按这条名称规则隐藏。其他实际节点的名称保持原样。

预览 51.1 验证后，经用户授权发布为正式版 1.5.2（versionCode 52），沿用正式签名与包名。
