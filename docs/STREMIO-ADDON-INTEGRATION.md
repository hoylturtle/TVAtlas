# Stremio HTTP 插件接入（测试阶段）

本次在现有 Android 原生影视聚合和 Media3 播放器上增加数据协议适配，不嵌入 Stremio APK、网页或执行插件代码，不改变代理订阅刷新策略。未公开发布。

## 使用

影视 → 影视插件；小屏幕为影视 → 更多 → 影视插件。可添加配置完成、以 `/manifest.json` 结尾的 HTTP(S) 地址，启用／停用／移除。插件配置地址可能包含账号密钥，因此只保存在本机 CredentialVault 加密存储；缓存来源字段使用不可逆标识，不写入完整插件地址、请求头或视频线路。没有新增观看事件上报。

内置两部 Blender Foundation CC BY 开放短片：Big Buck Bunny（2008）与 Sintel（2010），附影片署名和许可链接；影片媒体由 Internet Archive 存档提供。它们用于提供少量实际内容和验证接入闭环，不是新上映商业电影。首次初始化插件存储时加入，用户移除后不自动恢复。

Cinemeta 为手动添加的全球片目入口：提供资料和剧集结构，不提供播放地址。它不能单独带来可播放影视增量，界面明确标注“片目／待查询线路”。当用户安装匹配 IMDb 类型与 ID 的播放插件后，选中影片／某集才查询线路。自定义 ID 只向原插件查询，不凭片名猜测；季与集分开匹配。同 IMDb ID 的不同语言标题可合并，电影与剧集不合并，缺少统一 ID 的插件条目按来源隔离。

## 范围

支持 HTTP manifest、catalog（含声明的 search／skip）、meta、stream；支持标准电影和电视剧。目录仅选择不缺少必需参数的可浏览／搜索目录；分页按实际上一页数量累计 skip，目录响应最多 100 项、总聚合仍受原 1200 项限制。剧集最多 2000 条描述符。播放地址只存在内存，不缓存过期签名地址或请求头。

查询最多同时访问 3 个播放插件，总等待上限 12 秒；页面退出／后台取消沿用原有选择任务。支持 HTTP(S) 媒体 URL（含无扩展名）与白名单请求头；请求头只用于原媒体 origin，跨主机／端口／协议重定向删除这些头。插件 API 本身不跟随重定向，防止携带配置路径跳到未知服务，用户应填写最终地址。

BT/infoHash、磁力、YouTube ID、外部网页、压缩包、NZB、IPFS、旧版协议、播放器与媒体库事件均不执行；没有自动购买或共享付费账号。外部字幕插件尚未接入，现有内嵌字幕继续由播放器处理。电视支持的实际编码、HDR 和音轨仍取决于设备。

## 广告

默认显示“广告情况未知”，不能把没有反馈称为无广告。保留单条视频广告标记，并增加“屏蔽此来源”；该本机屏蔽覆盖来源后续影片和新 URL，自动选线在媒体测速前排除已标记地址／来源。被屏蔽的插件不参与播放线路请求。可通过清除广告标记恢复。屏蔽不删除片目，不对其他用户生效。

不基于 HLS 分片长度或 discontinuity 自动删片。画面中烧录的广告不可能通过换协议去掉，应更换不同来源／版本；手动跳过继续可用。

## 实测与验证

2026-10-28：Cinemeta manifest 可读取；官方公共领域插件缓存地址返回 403；官方静态示例 manifest／catalog／meta／stream 可读取，但其电影 CDN 返回 403，故没有内置或标为可播放。Google 示例视频 CDN 在本次环境也返回 403。Internet Archive 上两部内置短片的许可元数据可读，三个媒体样本均返回 HTTP 206、video/mp4 和 MP4 ftyp 数据。这里只验证到媒体可达，不代表整部影片逐帧检查无广告。

回归覆盖协议过滤、同名／IMDb／季集身份、带配置路径的资源构造、分页实际偏移、重定向请求头隔离、非法响应不回显密钥，以及本机加密配置和广告来源屏蔽持久化。实际电视与插件服务的地域可达性仍需实机测试。

本实现按公开协议独立编写，没有复制 Stremio GPL 实现代码或资源。
