# 历史约定功能核对（2026-10-18）

范围：当前 Android 客户端。代码存在不等于已在每个电视、网络、频道上实测成功。正式版目前为 1.5.3；本文包含尚未正式发布的本地改动。

| 约定 | 当前实现与入口 | 验收边界 |
| --- | --- | --- |
| 正式/预览并存、固定签名覆盖更新 | Gradle preview 独立包名、正式更新校验 | 预览数据不自动迁移正式版 |
| 启动先用本地频道、不阻塞首屏等待网络 | StartupPage、初始化后台任务 | 冷启动电视仍需真机日志验证 |
| 频道分组缓存、未变不反复计算 | ChannelBrowseCache 磁盘分类缓存 + 同进程完整索引复用 | 输入变化重新绑定，重启仍读磁盘 |
| 加载提示不铺满紫色 | ChannelBrowseLoading 容器与固定 4dp 进度条 | 已通过上一轮模拟器回归 |
| EPG 按观看/手动请求刷新 | PlayerViewModel.ensureGuide / refreshGuide 路径 | 外部 EPG 匹配率需频道样本 |
| 频道/代理默认 24 小时更新 | SettingsStore 及 refreshDue 到期判断 | 每小时检查到期，不是每小时下载 |
| 遥控焦点即时绘制与稳定恢复 | ImmediateFocusPaint、频道行固定 FocusRequester | 不保证所有设备无其他主线程卡顿 |
| 返回菜单、确认/长按分离、离开直播停止 | 根导航、播放输入策略与页面生命周期 | 遥控器实机型号仍需验收 |
| 影视聚合分类、地区/类型/年份筛选 | UnifiedVodRepository、VodCatalogPage | 元数据由来源提供，不保证分类无缺漏 |
| 影视首次加载、清空搜索恢复、缓存优先 | VOD 浏览生命周期、查询状态与分类缓存 | 无缓存与断网不能凭空生成新片 |
| 隐藏线路、优先高清、失败降级、连播 | VodLineSelector、VodPlaybackController | 限量候选探测，不保证全网最优画质 |
| 直播源与影视源统一管理、订阅到期更新 | MediaSubscription / VodSubscriptionStore | 原生 JSON 支持，受保护 Spider 未实现 |
| 代理紧凑布局、测速进度、完整批次、过滤说明项 | RoutingPage、LatencyMonitor、SubscriptionRepository | 测到延迟不证明视频服务可访问 |
| 字幕开关、语言选择、双语翻译 | 播放页字幕/翻译入口 | 仅独立文本字幕；画面内字幕不做 OCR |
| 模型下载进度、切页不断任务、英日韩转中文准备 | SubtitleTranslation、ModelDownloadProgress、TranslationSettings | 系统不提供字节数时显示未知，不能伪造百分比 |
| 设备翻译负载测试、通过才可启用 | TranslationGate、有效渲染时长检测 | 真实设备/模型下载/字幕轨仍需实测 |
| 翻译故障可诊断 | 新增 TRANSLATION 状态与测试资源指标，归入播放日志 | 不记录字幕内容、译文或异常正文 |
| 分开查看启动/播放/操作日志 | 调试日志类别、复制、TXT、扫码跟随类别 | 最近记录有容量上限；本次启动摘要独立保留 |
| 手机扫码看电视日志、扫码上传 APK | LogShareSession、ApkTransferSession、系统安装器 | 同局域网；不静默安装，不支持 XAPK |
| 台标补齐与缺图降级 | ChannelArtwork、channel-artwork-sources.json | 远端失效台标需要具体频道补样本 |

## 不能标为全部完成的历史项目

1. **设备管理后台、机器码、远程停用内置代理、收费授权**：当前仓库没有实现该服务。本轮是否包含等待用户确认。部署还需要服务器连接方式与客户端可达的服务地址，不能仅靠只有管理端可用的 SSH 隧道管理任意地点的客户端。
2. **APK 内置英/日/韩翻译模型**：现用 ML Kit 下载/缓存，接口不支持直接导入 APK 里的模型。已提供批量准备语言模型；若必须随包离线安装，需另选支持模型文件的引擎及可再分发模型并重新测兼容性，未以替代功能冒充完成。
3. **受保护 Spider 的完整兼容及其私有采集规则**：只提取订阅公开的原生 JSON 接口，不执行加密 JAR/脚本，也没有证据推断供应方私有采集系统。需要具体插件规范或可验证样本才能评估兼容实现。
4. **所有国家所有频道均可播放**：已存在多地区列表与代理路由，但服务地区限制、失效地址及授权无法凭代码消除；不能承诺澳门、台湾、日本及其他所有频道全部可用。
5. **电视真机流畅度与翻译可用性**：自动测试不代替用户电视的解码、DRM、网络、字幕轨和热状态验证。

## 影视源来源调查（项目代码证据）

`config/vod-subscriptions.json` 指向饭太硬、肥猫、王二小及公开原生配置。`VodSubscriptionStore` 解析订阅中可识别的接口；默认补充接口位于 `app/src/main/assets/vod-test-sources.json`。这些配置不是本项目维护的片源服务器。

客户端通过 MacCMS 风格的列表/详情 JSON 获取片名、分类及集数地址，再由播放器访问返回的媒体地址。一个采集 API、视频 CDN、实际权利人可以是不同主体；名称如“尤酷”“百度”不证明是对应官方平台。仅凭公开接口不能断言它们自行托管、取得授权或破解了某个平台。项目没有这些服务的服务端采集规则，因此不把推测写成调查结论。
