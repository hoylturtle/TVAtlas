# 本地／NAS 媒体与影视工具（待测试，未公开发布）

## 使用入口

影视片库工具栏或电视侧栏 → 本地／NAS。原来的网盘分享入口保留。

- U 盘／本机目录：点击“添加 U 盘／文件夹”，在 Android 系统选择器中授权所选目录。仅申请该目录的读取权限，不要求全盘管理权限。
- NAS：点击“连接 NAS”，填写名称、WebDAV 文件夹的 HTTP(S) 地址和账号密码。先验证该目录可读，再加密保存连接。只读取直接子目录及视频文件，不遍历全盘。
- 一次列表最多显示 2000 个视频或子目录，最多保存 64 个目录；当前页面离开或应用退到后台时取消在途目录读取。不是启动时的全盘索引或自动海报刮削。
- 支持视频文件名后缀 mp4、mkv、avi、mov、m4v、ts、m2ts、webm、mpg、mpeg、flv、3gp；实际编码、音轨和容器兼容性以设备和 Media3 播放结果为准。
- WebDAV 采用指定服务的 HTTP Basic 认证，不绕过证书校验。内置连接不会自动发现设备，不包含原生 SMB 客户端；SMB 目录仅在系统安装了相应 DocumentsProvider 时可从系统选择器授权。未承诺所有电视都预装系统目录选择器。
- U 盘未挂载、拔出、系统授权丢失时保留目录记录并提示刷新或重新授权；移除记录不删除原视频。
- NAS 地址及密码使用单独 CredentialVault 加密，不加入代理订阅、规则导出或观看记录。续播记录仍仅使用不透明内容键。连接不经过应用代理节点。

## 影视体验改进

- “本片线路”列出本次影片的候选来源、网络路径、连接中/失败/已出画面、实际播放测得的分辨率和首帧耗时；不会把片单接口响应速度冒充播放成功。列表按初始候选顺序保持稳定，不随异步结果打乱焦点。
- 可以手动选择或重试一条线路。已有广告标记不会被手动选择绕过。
- 保留已有按类型、片名、年份、地区匹配和同集编号匹配规则；新增时长差异保护：备用/手动切换到明显不同时长的版本时暂停，允许选择继续原进度或从头播放。旧进度超出新版本时长则不提供继续原进度。
- 缓存片单显示保存时间；已出结果时仍显示来源完成数及暂不可用数。短横屏也显示缓存/失败说明。
- “跳过片段”允许输入起止秒数，或用当前位置设置起止点；保存并启用后自动跳过，允许关闭自动跳过、移除区间和撤销刚发生的一次跳过。重叠区间合并。
- 手动区间仅绑定当前媒体地址，不能自动套用于其他来源/剪辑版本。换地址后未必保留区间，这是防止跳错剧情的刻意限制。没有新增默认自动识别或删除赌博广告的规则。
- 影视控制栏及较长表单支持滚动，保留原生 Media3、方向导航和此前的弹窗遥控修复。

## 验证边界

本轮包含 WebDAV XML/目录边界/凭证跳转单测、影片匹配和跳过区间单测，以及 content URI 离线播放、跳过与撤销的 Android 原生测试。实体 U 盘、各种厂商的 DocumentsProvider 和用户的 NAS 尚需现场验证。
