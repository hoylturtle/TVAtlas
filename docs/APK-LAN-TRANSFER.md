# 手机扫码传 APK 到电视

入口：设置 → 更新与诊断 → 手机传安装包。

电视和手机连接同一 Wi-Fi／有线局域网。电视临时开启绑定本机局域网 IPv4 的 HTTP 接收页，手机扫码选择一个 APK，双方显示进度。收到后读取 Android 应用清单及包信息，显示应用名称、包名和版本。点击打开系统安装器，由 Android 完成签名、兼容性及用户确认检查。首次使用可能需要允许 TVAtlas 安装未知来源应用，返回后再次点击安装。

- 单个 APK 最大 300 MiB，暂不支持 XAPK／APKS 分包。
- 随机令牌，十分钟有效；关闭窗口、退到后台或到期停止接收。
- 不上传云端，不静默安装，不自动执行包内代码。
- 流式写入私有缓存，检查可用空间，拒绝缺失长度／过大请求；失败清理部分文件，可重试。
- 精确校验 Host、Origin、令牌和路径；上传文件名不能决定落盘路径。
- FileProvider 仅开放 apk-transfer 子目录；完整文件暂留供系统安装器读取，下次打开接收页清理超过 24 小时的历史文件。
- 路由器开启客户端隔离、访客网络或设备不在同一局域网时，手机无法访问接收页。

验证：JVM 测试覆盖精确传输、路径隔离、大小及类型限制、跨来源拒绝、无效包后重试、重复接收拒绝、截断上传清理。Android 安装器需真机验证。

本轮结果：241 项 JVM 测试通过（app 147、core 94）；lintDebug、compileDebugAndroidTestKotlin、assemblePreview 通过。没有连接真机，未执行 Android 仪器测试或实际扫码安装。预览 50.1，不修改正式版发布通道。
