# 遥控器焦点与色块响应修正

用户报告多个页面焦点色块晚 1～2 秒出现，并存在方向、确认与返回交互异常。没有最新真机日志，不能仅凭静态代码确认全部延迟来源。

- 焦点装饰改为 FocusEventModifierNode + DrawModifierNode，收到焦点事件直接 invalidateDraw，不依赖可组合状态变更、重组或颜色动画。
- 电视按钮焦点背景在绘制阶段处理，Material 内容层透明，避免 Surface 覆盖反馈；手机按钮保持原有逻辑。
- 每个直播频道行使用固定 FocusRequester，不随 lastFocused 的变化插拔修饰器；恢复前滚动到目标行。
- 收起节目单时不为每次经过的频道更新节目单选择，节目单匹配按数据与频道记忆。
- 电视非直播页面返回时打开主菜单，保留页面；弹窗和详情页继续先处理各自返回。
- 增加 INPUT_QUEUE 和 INPUT_FRAME 超时记录，分别记录按键事件等待与帧回调延迟；帧回调不是实际屏幕呈现时间。只在遥控器键超过阈值时记录，不记录输入文字。

新增 Android 回归验证方向键切换后两个色块变化，且宿主内容不重组。需要模拟器执行及电视实机复测，不能用编译通过替代实测。
