# 网盘官方授权申请清单

适用于 TVAtlas 独立网盘预览版。整理日期：2026-10-15。

目标是让用户通过平台支持的扫码或 OAuth 流程授权自己的账号，在权限范围内浏览及播放有权访问的文件。**开发者应用获批、用户登录成功、分享可播放，是三个需要分别验证的环节。** 当前没有配置正式的网盘应用身份，不会显示可用的登录二维码。

### 项目介绍参考文字

> TVAtlas 是面向 Android 手机、平板及电视的个人媒体播放器，重点改善遥控器操作、目录浏览和播放稳定性。计划通过贵平台官方授权流程，让用户访问自己账号内及明确有权访问的网盘文件，并在获批能力范围内播放视频。项目不托管或转播媒体，不出售资源，不抓取用户密码，不绕过会员、版权或访问控制。当前分享导入及部分目录浏览已实现，账号授权与原生播放仍在开发。

这段文字应按申请平台及真实实现修改，不应承诺不具备的能力。

## 115：建议优先核实

官方入口：[115 开发者平台](https://open.115.com/)。官方说明列有个人云存储及播放等能力，开发者入驻需要审核；有开放平台不等于项目自动获得全部权限。

1. 用自己的账号进入官方开发者平台，查看个人／企业开发者准入及当前应用要求。
2. 按后台要求完成主体认证，提交拟使用接口、应用场景及要求的证明材料。
3. 创建或申请 TVAtlas 应用，说明 Android TV 的手机扫码场景及独立预览包。
4. 重点确认：允许的扫码／OAuth 模式、是否支持原生公开客户端、应用标识、回调要求、可申请的目录与播放权限。
5. 单独确认：**能否读取和播放他人分享中的文件，是否必须先转存，及所需会员／账号条件**。不可把“个人文件下载接口”直接视为“任意分享播放接口”。
6. 获批后记录应用标识、权限清单、审核结果和对应官方文档，才能设计真实扫码与授权回调。

尚未获批时，预览版只保留已实现的分享目录能力与官方网页入口，不借用其他客户端的应用身份。

## 百度网盘：申请应用及 OAuth 能力

官方入口：[百度网盘开放能力](https://yun.baidu.com/union/openAbility)、[百度 OAuth 说明](https://openapi.baidu.com/ms/oauth)。

1. 使用自己的账号进入网盘开放平台，核实当前开发者注册、应用创建及审核入口。
2. 创建 TVAtlas 应用，填写项目主页、应用用途、主体及联系方式等后台要求的信息。
3. 按平台当前支持的方案，确认 Android／电视设备授权方式及精确回调要求。
4. 按最小需要申请目录、文件信息和受支持的读取／播放能力；不主动申请删除、移动、上传等无关写权限。若平台把权限合并，需评估并向用户明确说明。
5. 重点确认获批能力的文件范围：自己的网盘文件、应用目录、分享文件是否属于不同接口或权限，是否需要转存。
6. 确认令牌交换是否需要保密的应用凭据。如果需要，不能将该密钥放进公开仓库或 APK，需要另行设计受控服务端；不要先把 Client Secret 发过来。

OAuth 账号接入说明不能作为“任意百度分享均可直接播放”的依据，实际能力仍需用获批应用验证。

## 夸克：先核实适用的开发者接入

官方资料：[夸克网盘 Skill 使用说明](https://www.quark.cn/documents/help/quark-drive-skill)。该页面描述 AI 助手接入，**不能直接推断 Android 第三方播放器拥有同等接口或授权范围**。

下一步需要向官方核实：是否接受本项目类型、是否提供适用的 Android／电视扫码授权、公开客户端的接入要求，以及分享文件读取和播放的范围。未核实前不承诺接入时间，不复用其他产品的登录身份，不把 AI 助手授权码当作播放器凭证。

## 获批后需要交接什么

可以先告知：平台名称、是否审核通过、应用类型、公开 App ID／Client ID、获批权限名称及官方文档链接。仅有这些公开配置也不代表可以立即上线，还需要回调和实机验证。

以下内容不要发到聊天或提交到 GitHub：Client Secret、Token、Cookie、密码、短信验证码、身份证材料和私钥。需要保密的配置将通过明确的本地或部署环境配置机制接入。

授权上线前需完成：

- 官方授权页面／二维码、过期与取消处理、回调校验和令牌安全保存。
- 用户主动退出账号与撤销授权，不影响直播订阅和其他网盘账号。
- 用获批接口验证目录、分享范围、临时播放地址、播放重试和权限不足提示。
- 如需转存，必须先向用户说明目标及影响并取得确认，不自动保存到用户网盘。
- 手机、电视和真实账号验收，核对隐私说明与实际请求一致后再进入正式版。
