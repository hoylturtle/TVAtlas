# TVAtlas

面向 Android 手机、平板与电视的直播与影视播放器，以及配套的频道订阅维护工具。当前稳定版本为 **1.5.0**。

**这个项目起于对市面上直播工具的使用体验不满意：选台、订阅管理、地区路由和播放失败处理，往往很难同时做好。因此决定自己制作一个更符合实际观看习惯的工具。**

TVAtlas 的目标是稳定观看，而不是搜集“免费直播源”或堆积频道数量。我们更关心频道是否有可靠入口、网络是否符合服务要求、失败后能否合理回退，以及出了问题能否定位原因。有公开入口不代表在所有地区都能看；有代理也不代表具备观看权限。

[下载 Android APK](https://github.com/hoylturtle/TVAtlas/releases) · [播放器与构建说明](android-player/README.md) · [使用边界与免责声明](DISCLAIMER.md)

## 项目定位

- 优先维护常用频道和可解释的播放流程，重视实际观看质量。
- 对已接入的香港频道，使用官方服务入口，由播放器按需获取会话和播放配置；这些实验性接入并非电视台官方合作或授权客户端。
- 允许用户导入自己的频道列表、代理订阅和路由规则，适配自己的设备、网络和合法观看条件。
- 不承诺所有频道永久可用，不提供付费内容解锁、DRM 破解或观看权限。

项目不经营代理套餐，不出售频道或网盘资源。合法订阅、服务账号及相关费用由用户自行向对应服务商确认。

## 功能与使用方式

| 范围 | 当前能力与边界 |
| --- | --- |
| 直播 | 默认频道、用户 M3U 列表、搜索、收藏、最近观看；按地区 → 频道类型 → 频道浏览 |
| 手机与电视 | 手机／平板横屏全屏；电视遥控器选台、确认播放、返回和浮层频道面板 |
| 线路与回退 | 多线路、节点测速、同地区候选节点回退及播放错误诊断；候选均不可用时仍会失败 |
| 代理与规则 | Clash/Mihomo 节点订阅、HTTP/SOCKS5 代理、默认地区路由与用户自定义规则 |
| 观看信息 | 节目单、线路与节点信息、延迟及即时网速；节目单只保留已导入频道当前及未来 24 小时安排，节目条目数不等于直播频道数 |
| 流量 | 区分直连与代理流量，查看节点统计；服务商返回套餐信息时显示额度、余量和到期时间 |
| 设置与维护 | 网络使用偏好、移动数据提醒、配置管理、脱敏调试日志、签名 APK 更新 |

应用内流量是本应用所统计请求的收发数据，不等同于运营商账单或代理套餐扣费。套餐余量来自订阅服务商，可能包括其他设备的用量，也可能缺失或延迟更新。节点延迟低，不代表目标视频 CDN 可达、带宽足够或能够通过地区检查。

### 1.5 影视、网盘与字幕

1.5.0 将预览 44.1 的统一影视片库带入正式版：按电影、剧集、综艺、动漫、短剧浏览，支持类型、地区、年份和排序筛选，跨来源合并同一影片，优先选择高清可用线路并在失败时回退。首次进入自动加载，清空搜索恢复片单。来源与网络路线在频道源中管理；原始订阅仅接入可验证的原生 JSON 接口，不运行远程 JAR／JS／JNI 插件。

夸克、百度网盘、115 分享提供链接识别、加密保存及部分匿名目录读取；**官方账号授权与原生网盘取流尚未完整接入**，成功列出文件不代表可以原生播放。可用视频直链支持暂停、拖动、音轨／字幕选择和本机续播。官方授权申请资料见 [网盘接入申请清单](docs/cloud-platform-onboarding.md)。

直播增加独立字幕开关与本机文字字幕翻译。英／日／韩到中文模型可首次联网准备，之后离线使用；启用翻译前需在可见直播画面通过本机性能测试。仅处理独立文字轨道，不识别画面新闻条或语音。离开直播页将停止直播，返回后由用户主动播放。

正式版与独立预览版的数据互相隔离。1.5.0 沿用固定正式签名，可覆盖旧正式版保留配置；独立 Spider 兼容测试器不包含在本正式 APK 中。

## 频道订阅与定制

### 默认订阅

APP 将内置入口统一展示为一条「TVAtlas 默认频道」，内部按频道处理官方入口与普通直播列表。合并展示不意味着所有频道都来自同一网站或采用相同播放协议。

普通 M3U 订阅地址：

```text
https://raw.githubusercontent.com/hoylturtle/TVAtlas/main/tvatlas.m3u
```

默认配置包含中国大陆、香港、澳门、台湾、日本、韩国等地区的频道，也可包含其他地区。频道范围以当前配置和列表为准；**列入订阅不等于已经在你的地区和设备验证可播**。

普通播放器可导入 M3U，但 APP 中动态会话、官方授权和源适配等能力，不会因为导入同一个 M3U 自动出现在其他播放器中。

### 你可以定制什么

1. **频道列表**：在 APP 中添加自己的 HTTP(S) M3U 地址，管理和刷新个人频道源。请使用有权访问和观看的来源。
2. **代理订阅**：单独导入包含节点的 Clash/Mihomo 订阅。它提供网络节点，不提供电视频道或内容权限；频道订阅与代理订阅是两种不同配置。
3. **路由规则**：使用内置地区规则，或导入自定义 JSON 规则文件；多个规则文件只选择一个生效，默认地区策略作为回退基础。频道及单线路手动设置也会影响最终路由。
4. **维护自己的频道集合**：修改 [config/channels.json](config/channels.json) 中的频道名称、地区、分组与匹配别名；上游列表及候选优先级在 [scripts/build.py](scripts/build.py) 中维护。建议先在自己的分支验证。

规则格式示例见 [routes-v1.json](android-player/examples/routes-v1.json)。规则导出不包含代理密码和完整订阅凭证，迁移设备后需要另行导入对应代理订阅。

### 默认地区路由

| 频道地区 | 默认方向 |
| --- | --- |
| 中国大陆 | 直连 |
| 香港、澳门 | 香港地区节点 |
| 台湾 | 台湾地区节点 |
| 日本 | 日本地区节点 |
| 韩国 | 韩国地区节点 |

这是一套网络选择策略，不是平台可用性保证。澳门频道使用香港节点也可能不满足其授权地区；节点名称写着“香港”或“解锁”，也不能证明实际出口被服务认可。自定义规则、手动路由及可用节点会影响最终结果，实际路线以播放信息和日志为准。

电视界面中，紫色实底表示当前选中项；白色边框表示遥控器光标位置。移动焦点不会改变当前页面或频道，按确认后才执行选择。

## 地区限制为什么会影响观看

直播能否稳定播放，取决于完整链路：频道入口 → 会话／播放配置 → 清单 → 视频分片 → 必要的 DRM 授权。入口网站打开或接口返回 HTTP 200，只能证明某一步成功。

- **版权与地区**：服务可能只向特定国家或地区开放，还可能检查账号、出口 IP、运营商或设备。
- **网络与 CDN**：官网、视频 CDN 和授权服务器可能位于不同网络；某个节点能打开网站，不代表能持续下载视频。
- **账号与设备**：部分内容需要有效订阅、登录、受支持的 Widevine 环境或官方客户端。
- **地址与接口变化**：签名地址会过期，官方接口及第三方上游也可能调整或停止服务。

回退只能尝试已有且符合策略的其他线路或节点，不能创造不存在的播放源，也不能替代账号、地区资格或内容授权。请遵守当地法律及服务条款；无法满足要求时，使用服务方支持的官方观看方式。

## 架构

```text
频道维护：config/channels.json + 上游列表
                       ↓ Python 构建与探测
                 M3U + CI 诊断产物
                       ↓
Android APP：Compose 界面 → ViewModel / 播放协调器
                       ├─ core：列表解析、规则匹配、回退规划、节目单模型
                       ├─ 源适配：官方会话、动态播放配置
                       ├─ 网络：OkHttp + 应用内 Mihomo / HTTP / SOCKS5
                       ├─ 播放：Media3 / ExoPlayer + 平台 Widevine
                       └─ 存储：Room、偏好配置、Keystore 加密凭证
```

- **维护层**负责收集候选地址、匹配频道并生成列表，不托管或转播视频。
- **核心层**将解析、路由和失败处理与 Android 界面分离，便于独立测试。
- **播放层**处理清单、媒体及官方授权请求；使用正常的平台 DRM 流程，不提取解密密钥。
- **网络层**为本应用选择节点，不建立供其他应用使用的系统 VPN。外部浏览器不会自动继承 APP 内代理。
- **诊断层**记录受控错误、域名和阶段信息，便于区分源、网络、授权和设备问题。

## 自动维护与健康状态

GitHub Actions 按工作流计划或相关变更运行构建，拉取上游列表、匹配频道并探测候选线路，输出 M3U。诊断报告作为 CI artifact 保存，不作为源码目录或 Release 下载附件发布。

| 状态 | 含义 |
| --- | --- |
| `healthy` | 构建节点上的探测成功，不等于所有地区和设备均可播放 |
| `fallback-unverified` | 有候选地址，但构建节点未验证成功；可能受地区或网络影响 |
| `missing` | 当前未找到可用候选地址 |

云端探测不能代替家庭网络、目标地区及真实设备上的持续播放验收。

## 安装、开发与反馈

从 [Releases](https://github.com/hoylturtle/TVAtlas/releases) 下载 `.apk` 安装。`release-info.json` 用于更新校验；校验文件、构建信息及 Mihomo 许可证／对应源码不是需要安装的文件。固定签名且版本号更高的正式包支持覆盖更新。

开发环境为 **JDK 21、Gradle 8.11.1、Android SDK 35**。详细构建、签名和预览包说明见 [android-player/README.md](android-player/README.md)。

反馈播放问题时，请提供版本、设备、频道名称、所在地区、直连／代理情况及失败附近的脱敏日志。不要提交订阅私密地址、提取码、密码、Token 或 Cookie。日志不自动上传；分享前仍应检查其中的频道名、节点名和设备信息。
