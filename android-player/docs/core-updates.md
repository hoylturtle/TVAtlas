# 内核随 APP 发版更新

代理页内核页签显示打包内核版本、ABI、可用与运行状态。“检查 APP 更新”跳转设置页并检查应用更新，没有独立内核下载和安装入口。

内核通过包含新版 libmihomo.so 的签名 APK 更新，复用文件摘要、固定签名、包名、版本和系统安装确认流程。发版前验证新内核与订阅协议兼容性。

发布者更新 mihomo-lock.json 中版本、四 ABI 地址与官方 SHA-256，并同步 release-info.json 的 coreVersion。构建从锁定文件生成 BuildConfig.MIHOMO_VERSION，验证官方二进制摘要并提供对应源码；发布脚本拒绝锁定版本与清单不一致的包。原生与覆盖安装检查通过后才公开发布。
