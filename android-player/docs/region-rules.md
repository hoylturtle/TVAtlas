# 地区路由、规则文件与测速

内置地区规则只读：大陆直连；港澳使用香港节点，台湾、日本、韩国使用对应地区节点。识别频道分组及 tvg-id 地区标记，节点地区按名称中文、旗帜或常见代码识别。未找到对应地区启用节点时明确提示，不自动改用其他地区。

规则文件可导入多个，事务切换保证同时只选中一个。导入后自动选择新文件；选择“仅使用内置规则”保留所有导入文件但取消启用。命中选中文件的规则时覆盖内置路由，未匹配频道使用内置地区规则。手动频道/线路选择优先。数据库 2→3 保留原有规则为一份已选中规则文件。

测速测量经实际代理的 HTTPS 204 响应耗时，并非 ICMP ping。手动测速取最多三次有效响应的中位数，四路并发，有响应与整批截止时间；超时未测节点保留“未测速”状态。自动播放补测五分钟内无有效缓存的候选节点，最多等待十秒。订阅更新时旧测速结果失效。

排序为可达低延迟节点、未测速节点、近期不可达节点。历史仅影响频道源优先级，不让旧成功节点覆盖新测速排序。自动播放网络错误回退其他同地区节点，并跳过当前会话中已网络失败的节点。测速可达不代表该节点对某一频道具有地区权限或播放授权。
