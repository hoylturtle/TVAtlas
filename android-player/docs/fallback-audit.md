# TVAtlas 播放回退与项目审计（2026-10-12）

本轮围绕 0.1.23 真机日志审计播放、代理路由、订阅与更新、持久化、日志、局域网输入、发布校验和手机/电视界面。修复版本为 **0.1.25（26）**。这份报告不等同于完整渗透测试或“项目没有任何 BUG”的保证。

## 主要问题与修复

| 严重程度 | 问题 | 修复与验证方式 |
| --- | --- | --- |
| 高 | 手动代理只生成一个播放候选，失败即结束 | 手动节点作为首选；失败后使用对应地区节点。停用/移除的首选节点也可使用地区保底。直连及自定义规则的明确策略保持原意。地区回退单元测试覆盖顺序、停用节点与边界。 |
| 高 | 第三方媒体子请求会重新绑定手动首选节点，导致“已回退”仍走原节点 | HLS 分片、密钥和重定向继承当前具体回退节点。通过两个模拟 HTTP 代理确认备用节点实际收到请求，原节点没有收到。 |
| 高 | DRM 网络初始化错误没有独立保底；永久设备错误又可能按网络盲目重试 | Google/Widevine 设备初始化最多尝试首选、直连和一个同地区备用节点，每次最多 4 秒；TVB/ViuTV 授权仍走取得会话的节点。网络错误回退，401/403 可重新获取一次会话，设备或非重试授权错误跳过该源。测试验证初始化/授权隔离、TLS 回退、最多三条初始化链路。 |
| 高 | 频道生成脚本将大段 JSON/文本误判成视频，HTML 等已确认无效地址仍进入备用池 | 检查常见媒体容器，排除确定无效的响应；保留超时或地区限制等尚不能判定无效的候选。DASH 单独标注未验证。标准香港订阅保留最多三条候选，供 APP 换源。Python 模拟响应测试覆盖。 |
| 中 | 取消阻塞下载/订阅后，连接继续占用，取消还可能变成普通网络异常 | 取消时关闭具体 Call，包括响应体读取；保留协程取消语义。模拟无响应服务验证及时取消，不等待 30 秒读超时。 |
| 中 | 保存路由后立即播放，可能读取旧频道配置 | 播放等待已排队的配置操作完成，再读取数据库快照，使用新的频道和路由。原子恢复自动路由不会删除来源或成功历史。 |
| 中 | 一个 CDN 失败把同节点的其他播放源也排除 | 网络故障仅排除当前源上的该候选，其他来源仍可尝试。场景单元测试覆盖。 |
| 中 | 频道和流按重复扫描组合，大列表在主线程处理 | 按频道预先索引流，组合与规则解析移到后台；保留来源开关、重复 URL 合并与原有顺序。 |
| 中 | 更新直连失败没有自动网络策略，操作中没有取消入口 | 新安装默认自动更新网络：直连后最多尝试两个已有节点；保留旧的手动网络偏好。检查/下载均提供取消，仍执行大小、哈希、版本与固定签名校验。 |
| 中 | 来源配置拒绝被当成坏节点，污染测速结果 | 配置、地区拒绝与网络异常分别分类，不把不支持的源或地区拒绝直接当成节点不可达。 |

## UI 审查与调整

界面证据来自**本轮重新运行的 Android 原生组件测试截图**，使用合成频道与节点，不包含真实账号、订阅 URL 或授权凭据。截图覆盖实际 Compose 组件，但不是完整真机端到端录屏。

1. **代理订阅管理 — 已调整**：旧层级把下载网络卡片放在订阅前。订阅卡片现在紧跟添加按钮，更新进度和错误留在对应卡片上；下载网络设置后置。测速结果说明是通用 HTTPS，不承诺每个直播 CDN 都可达。
2. **设置更新 — 已调整**：保留紧凑卡片和折叠帮助，突出检查更新；增加自动网络和取消操作。明确手动更新网络不静默换节点。
3. **电视频道与导航 — 保留并修正一致性**：焦点使用实色高亮和白边，遥控器行为测试覆盖方向键与确认键。导航统一为“直播 / 频道源 / 代理 / 设置”，避免手机和电视叫法不同。分组增加展开状态语义。
4. **播放失败恢复 — 新增**：失败卡片提供“重试播放”和“切换线路”；线路弹窗解释源级代理优先，并提供一键恢复自动路由。最后一次源和节点仍可辨认。窄屏行为与截图检查覆盖。

## 已检查的其他部分

- Room 迁移、来源刷新保留设置、规则文件单选、失败刷新保留旧节点。
- 凭证通过本机 Keystore 保护；规则导出不包含密码，日志不包含请求/响应体及凭据。
- 局域网扫码接收有随机路径、Host/Origin 校验、五分钟过期、单次使用和输入大小限制，电视端确认后才导入。
- APK 更新检查公开发布资产；下载后检查大小、SHA-256、包名、递增版本和固定签名，系统安装确认仍保留。
- Mihomo 保持 v1.19.32，随签名 APK 发版更新；许可证与对应源码继续提供。

具体 CI 结果以 [PR #31](https://github.com/hoylturtle/TVAtlas/pull/31) 和签名发布记录为准。本地 Python 健康/备用源选择测试通过；Android 单元、静态检查、设备回归、覆盖安装检查由 CI 执行。

## 验证边界与后续关注

- 尚未用用户的私有香港节点在 Xiaomi Android 36 上完成实际 Widevine 初始化和持续播放；需要安装后验证。回退不代表所有节点和官方服务都一定可用。
- 通用测速与特定 CDN/Google 可用性不同；“直连”仍使用 Android 系统网络，外部 VPN 可影响出口。
- 同名频道当前按名称合并；不同地区恰好同名的自定义来源需要不同频道名称。改用地区或 tvg-id 区分需要保留历史与手动规则的数据迁移，未在本轮直接改变标识。
- 尚未完成 TalkBack 真机朗读、所有字体缩放档位、所有电视遥控器型号、所有 Android ABI 与第三方依赖漏洞扫描。本轮不宣称完整无障碍合规。
