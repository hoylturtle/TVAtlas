# v0.1.4 实机验收

以下项目必须在真实手机、平板和电视/盒子上验证。目前不能将 CI 编译成功等同于这些项目通过。

| 场景 | 操作 | 预期 |
| --- | --- | --- |
| 安装/启动 | API 23+ 手机、平板和 Android TV 安装调试 APK | 正常启动，TV 启动器显示应用 |
| 分组默认折叠 | 首次进入直播页、展开/收起分组、搜索并清空 | 默认仅显示组名；搜索展示匹配频道；清空恢复原展开状态 |
| 简洁选择 | 选择线路与订阅节点 | 收起后仅显示名称，不暴露 URL、节点 ID；同列表多线路按序号区分 |
| 频道面板 | 电视选台后按 OK / 左键 / 返回 | 选台收起面板，按键可重新打开，焦点可见 |
| 中文 M3U | 添加带 BOM、中文和同名多 URL 的播放列表 | 中文正确，同名合并，URL 去重 |
| 无代理 | 不添加代理，播放有效 DIRECT 源 | 正常播放 |
| 双代理 | 添加两个本机可达的 HTTP/SOCKS5 端点 | 可分别编辑、启停和保存认证 |
| 订阅导入 | 导入包含 SS/VMess/VLESS/Trojan 的真实 YAML 订阅 | 下载并校验成功，节点可选择、启停；实际直播经所选节点播放 |
| 订阅更新 | 更新同名节点、错误订阅、删除订阅 | 同名 ID 和路由保留；失败保留原数据；删除清理节点与凭证 |
| 多架构 | ARMv7/ARM64 手机或盒子运行订阅节点 | 内核启动并转发；切到后台停止播放 |
| AUTO | 有效代理源 + 直连失败，规则 try 为 DIRECT/US/HK | 在超时/错误后逐个切换 |
| 重启记忆 | 等待播放持续成功后重启应用，再次选择频道 | 优先成功线路与允许的成功路由 |
| 强制直连 | 在具有 US 历史的频道设置 DIRECT | 所有请求直连，历史不覆盖设置 |
| 线路覆盖 | 频道 PROXY，单线路 DIRECT | 该线路优先其手动设置 |
| HLS 继承 | 使用不同域名的 master/variant/segment/key 源 | 子请求默认走当前会话路由 |
| 跳转规则 | m3u8 302/307 至另一域名并配置域名规则 | 下一跳重新选路，无认证头跨域泄漏 |
| 线路错误 | 分别制造 404、清单错误、解码错误 | 跳到下一线路，不重复同 URL 换代理 |
| 配置文件 | 文件选择器导入有效/无效/未知代理/未知版本 JSON | 有效导入；无效保留原配置并提示 |
| 刷新保留 | 同频道更新列表，更换部分 URL | 频道设置保留，现存线路历史保留 |
| 生命周期 | 快速换台、停止、返回、进入后台 | 无旧回调误切台，主动停止不计失败 |
| 电视 D-pad | 无触摸完成导航、搜索、OK、长按 OK、线路菜单及代理输入 | 焦点可见，无焦点陷阱，返回行为正确 |
| 检查更新 | 设置中检查当前版本、新版、断网和无浏览器电视下载链接复制 | 仅成功且有未过期 APK 的构建提示升级；失败可重试；链接可复制 |
| 隐私 | 导出规则、查看诊断和错误记录 | 无用户名/密码/Token；地址路径及查询脱敏 |

注意：示例 JSON 的 127.0.0.1 是播放器所在设备自身。家庭局域网代理应替换为对应设备的实际地址，端口由用户自行配置。勿将真实凭证提交至仓库。

## 官方翡翠台原型（0.1.5）
- 添加官方列表后配置线路代理；验证会话、checkout、MPD/视频和 DRM 同走选定线路。
- 在支持 Widevine 的真实 Android 设备验证首播、持续播放、停止后重播；模拟器通过不代表 DRM 实播成功。
- 不支持设备/地区/平台拒绝返回受控错误，不能出现 token 或签名 URL。
- 网络 401/403 只续期一次，再失败继续切换；停止/切台时取消会话获取。
- 不允许把用户截图中的 token、Cookie、签名写入源码或安装包。
